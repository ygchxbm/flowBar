## FlowBar 0.2.1

针对 0.2.0 的稳定性与数据准确性修复，保留现有六项指标和 macOS 13 最低版本。

### 修复与优化

- 系统采样移至后台串行执行，合并重复刷新；面板隐藏或展示值未变时减少界面更新。
- 网速改用单调时钟，唤醒后重新建立采样基线，避免校时和休眠干扰。
- 修正不同容量单位的电量换算，并处理电池不存在、非法数值和越界输入，避免异常数字导致崩溃。
- 登录项需要系统批准或操作失败时提供明确提示；补充开关的无障碍标签。
- 面板支持 Escape 收起，数据刷新时保持位置稳定。
- 按需读取备用电池温度数据，减少重复系统查询。

### 开发与验证

- 增加采样调度、休眠恢复、电池解析、展示去重和登录项状态的测试覆盖。
- 新增 GitHub Actions，执行测试、严格并发检查及 Release 打包签名验证。
- 调试构建保留调试信息，构建脚本校验配置参数和应用签名。
- 版本标签触发自动发布，测试、并发检查与打包校验通过后上传应用和 SHA-256 校验文件。

### 已知限制

- 没有新增指标或提高最低系统版本。
- 登录项待批准分支、双屏/全屏面板位置以及 macOS 13 / Intel 兼容性尚未实机验证。
- 电池温度与功率依赖系统数据，传感器缓存延迟仍可能存在。
- 应用包仍采用 ad-hoc 签名，未进行 Developer ID 签名或公证。
- 发布附件包含 `FlowBar.zip` 和 `SHA256SUMS.txt`。
