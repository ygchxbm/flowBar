## FlowBar 0.2.0

新增上传速度与菜单栏显示切换，改进网速统计和弹窗交互。

### 新增功能

- 新增上传速度，显示在下载速度下方。
- 菜单栏支持选择下载速度、上传速度、电池温度、电池功率、电量或供电状态。
- 通过弹窗内的左右按钮依次切换显示内容，并记住上次选择。
- 更新应用图标。

### 修复与优化

- 改用 64 位网络流量计数，筛选活动硬件网卡，避免虚拟接口重复统计导致网速偏高。
- 下载与上传速度使用同一次采样数据，分别计算收发速率。
- 打开弹窗或收到系统电源变化通知时立即刷新电池信息。
- 弹窗中的电池温度和功率保留一位小数，菜单栏保持整数紧凑显示。
- 将“充电功率”调整为“电池功率”，正值表示充电，负值表示放电。
- 为菜单栏切换按钮、退出按钮和登录时启动开关添加手形光标反馈。

### 已知限制

- 支持 macOS 13 及以上版本。
- 网速仍按约 2 秒间隔采样，显示当前网络流量速率，不代表宽带最高带宽。
- 电池温度与功率依赖系统数据，部分机型可能存在数十秒的缓存延迟；立即刷新不代表传感器立即产生新读数。
- 不保存历史记录，也不提供图表或告警。
